CALEON CLIENT (Fabric 1.21.4)
1. Create a GitHub repo, upload ALL files/folders from this project (keep the folder structure, including .github).
2. Open the Actions tab -> "Build Caleon Client" -> wait for the green check.
3. Open the finished run -> Artifacts -> download caleonclient-mod.
4. Unzip it, put caleonclient-1.0.0.jar in .minecraft/mods with Fabric Loader + Fabric API for 1.21.4.
Right Shift = menu. Left click = toggle, right click = settings.
